<header>
    <h1>Three Things That Changed How I See Coding</h1>
    <p>
        Before this week, coding seemed like something that required knowing
        a bunch of complicated computer language. After spending time working
        with HTML, Visual Studio Code, and GitHub, I realized that coding is
        less about memorizing everything and more about learning how to think.
        Here are three of my first impressions from this week.
    </p>
</header>

<main>

  <section>
      <h2>1. HTML Feels Like Giving Instructions to a Browser</h2>

  <p>
            One of my first surprises was realizing that HTML is not really
            about making a webpage "look good." Instead, it is more like giving
            the browser a set of instructions about what everything means.
            A heading is a heading, a paragraph is a paragraph, and a section
            is a section. Once I understood that, the code started to feel
            less random.
    </p>

  <p>
            I also started noticing HTML when I look at websites outside of
            class. Things that used to blend together, like headings,
            navigation areas, and paragraphs, now make me wonder what tags
            are being used behind the scenes. It feels a little like learning
            how a magic trick works and then being unable to look at it the
            same way again.
      </p>
  </section>

  <section>
      <h2>2. Debugging Is Basically Playing Detective</h2>

  <p>
            Another thing that stood out to me was how easy it is to make a
            small mistake in code. A missing character or tag can create a
            problem somewhere else on the page. My first reaction was that
            something had simply "broken," but I am beginning to see debugging
            differently.
  </p>

  <p>
            Debugging feels more like detective work. I have to look at what
            the computer is doing, compare it with what I wanted it to do,
            and then search for the clue that explains the difference. It can
            be frustrating when I cannot immediately find the problem, but
            solving it is also one of the most satisfying parts of coding.
    </p>
    
  </section>

  <section>
    <h2>3. GitHub Makes Progress Visible</h2>

  <p>
            My third impression is that GitHub makes coding feel more like an
            actual project instead of just an assignment sitting on my
            computer. Creating a repository gives the project a home, and
            saving my work there makes it easier to see what I have created.
    </p>

  <p>
            I like the idea that my projects can show progress over time.
            Instead of only remembering what I struggled with, I can eventually
            look back at older work and see how much I have improved. That
            makes coding feel less like trying to get everything perfect on
            the first attempt and more like building a collection of skills
            one project at a time.
    </p>
</section>
